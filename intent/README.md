# Active plans and retained evidence

Keep documents here only while they govern unfinished work, supply a current protocol
contract, or substantiate a reported result. Completed implementation plans and superseded
reviews belong in Git history, not an archive directory. Overall status lives in [VISION.md](../VISION.md).

For new changes, use `YYYY-MM-DD-slug/{intent,spec,plan}.md`, follow the approved
stage workflow, and remove completed planning documents once durable operational
guidance and relevant results have been retained.

Retaining a plan does not authorize deployment or spending.
